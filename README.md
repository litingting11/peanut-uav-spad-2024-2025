# peanut-uav-spad-2024-2025
Raw dataset (2024–2025) supporting "UAV-derived 3D canopy reconstruction enables vertical SPAD profiling in dense peanut canopy".
This repository documents data associated with the peanut UAV–SPAD study conducted in 2024 and 2025 and provides access to the shared data files.
Given the size of the dataset and the ongoing data organization and curation process, data are being organized and released in stages. To facilitate access, selected raw data files are currently available through Baidu Netdisk.
